TS로 만든 작은 신경망 뉴런

2026-10-31

들어가기에 앞서

저는 전문가가 아니고, 재밌어서 만들어 본 거라 내용은 정확하지 않을 수 있습니다.

구현한 작은 뉴런 하나

클로드의 설명으론 로지스틱 회귀를 확률적 경사 하강법으로 학습시킨 것이라고 거창하게 평가해주는데, 이름은 거창해도 제가 만든 건 작고 소중한? 뉴런 하나입니다.

// ===== 뉴런: σ(w·x + b) =====
function dot(x: number[], w: number[]): number {
  let sum = 0;
  for (let i = 0; i < x.length; i++) {
    sum = sum + x[i] * w[i];
  }
  return sum;
}

function sigmoid(z: number): number {
  return 1 / (1 + Math.exp(-z));
}

function neuron(x: number[], w: number[], b: number): number {
  const z = dot(x, w) + b;
  return sigmoid(z);
}

한 단계씩 제가 이해한 대로 설명하자면

  1. neuron 함수는 입력, 가중치, 편향을 받아서 dot(입력, 가중치) + 편향을 z에 계산해 넣습니다.
  2. 그렇게 구한 z값을 sigmoid 함수에 넣어 계산합니다.
  3. 이후 sigmoid가 계산한 값(0~1 사이)을 결과로 반환합니다.
  4. sigmoid 함수는 간단하게 말해서 z값이 클수록 1에 가깝게, 작을수록 0에 가깝게, 0이면 0.5를 뱉어주는 함수입니다.
  5. dot 함수는 입력의 길이만큼 입력 * 가중치를 계산하고, sum에 더해주고, 결과를 반환하는 함수입니다.
  6. dot, sigmoid 함수는 결국 neuron 내부 계산을 위한 함수라고 보시면 됩니다.

어떤 걸 계산하는가?

// ===== 데이터 (AND): x는 입력, y는 정답 =====
type Sample = { x: number[]; y: number };

const data: Sample[] = [
  { x: [0, 0], y: 0 },
  { x: [0, 1], y: 0 },
  { x: [1, 0], y: 0 },
  { x: [1, 1], y: 1 },
];

제가 만들어본 작은 뉴런 하나에는 AND 게이트 계산을 시켜봤습니다. x는 입력, y는 정답입니다.

학습 전

// ===== 시작 값 (랜덤) =====
const w: number[] = [Math.random() * 2 - 1, Math.random() * 2 - 1];
let b: number = Math.random() * 2 - 1;
const eta = 0.5; // η: 학습률

w(가중치), b(편향)는 랜덤 함수로 계산해서 할당하고, eta는 학습할 때 사용하는데, 가중치와 편향을 얼마나 크게 고칠지(보폭) 정하는 값입니다. eta가 클수록 한 번에 크게 조정하고, 작을수록 세세하게 조정하며 학습합니다.

console.log("--- 학습 전 ---");
for (const sample of data) {
  const yHat = neuron(sample.x, w, b); // ŷ: 예측
  console.log(sample.x, sample.y, yHat.toFixed(3));
}

학습 전 계산을 시켜보면 sample.x(입력), w(랜덤 가중치), b(랜덤 편향)를 neuron 함수에 넣고, 나온 예측값을 yHat에 저장합니다. 이후 간단하게 콘솔 로그로 입력, 정답, 계산 결과를 출력합니다.

--- 학습 전 ---
[ 0, 0 ] 0 0.310
[ 0, 1 ] 0 0.143
[ 1, 0 ] 0 0.397
[ 1, 1 ] 1 0.196

학습 전에는 여러 번 실행해봐도 정답 근처에도 가지 못하는 걸로 보였습니다.

학습

// ===== 학습: w ← w + η(y − ŷ)x, b ← b + η(y − ŷ) =====
for (let epoch = 0; epoch < 1000; epoch++) {
  for (const sample of data) {
    const yHat = neuron(sample.x, w, b);
    const error = sample.y - yHat; // y − ŷ

    for (let i = 0; i < w.length; i++) {
      w[i] = w[i] + eta * error * sample.x[i];
    }
    b = b + eta * error;
  }
}

제 얕은 지식으로 봐도 어려워 보이는 코드인데 대강 설명해 보자면, epoch < 1000 즉 데이터 4개를 1000바퀴(총 4000번 조정) 학습시키는 코드입니다.

  1. yHat은 학습 전처럼 neuron 함수를 돌려 얻은 예측값입니다.
  2. error는 y(정답) - yHat(결과)로 정답에서 계산 결과가 얼마나 차이 나는지 계산해 넣습니다.
  3. 이후 for문을 돌려 w(가중치)를 하나씩 조정하고, for문이 끝나면 b(편향)를 조정합니다. 이때 w와 b 모두 eta(학습률)를 곱해 조정합니다.
  4. w(가중치)는 원래 가중치 + (학습률 * 오차 * 입력)으로 조정합니다. 입력을 곱하는 이유는 책임을 나누기 위함입니다.
  5. 책임이란 간단하게 입력이 0일 때는 가중치를 안 썼으니 0을 곱해 조정을 안 하고, 입력이 1일 때는 가중치가 사용되었으니 1을 곱해 조정값을 살립니다. 입력이 클수록 그 가중치를 더 크게 조정하는 셈입니다.
  6. b(편향)는 입력을 곱하지 않고 학습률 * 오차로 조정합니다. 편향은 입력과 상관없는 값이라, 입력이 항상 1인 가중치로 볼 수 있기 때문입니다.

학습 후

console.log("--- 학습 후 ---");
for (const sample of data) {
  const yHat = neuron(sample.x, w, b);
  console.log(sample.x, sample.y, yHat.toFixed(3));
}
console.log("w:", w, "b:", b);

학습 전과 같은 코드지만, 위에서 for문으로 w(가중치), b(편향)가 조정되었기 때문에 이번에는 정답에 가까운 값을 출력합니다.

--- 학습 후 ---

[ 0, 1 ] 0 0.010
[ 1, 0 ] 0 0.010
[ 1, 1 ] 1 0.986

간단한 코드라 여러 번 실행해 봐도 학습 후에는 항상 정답에 아주 가까운 값을 냅니다. 100줄도 안 되는 코드인데 어렵기도 하고, 나름 재밌어서 가끔 더 어려운 것도 하나씩 해보면 좋을 것 같습니다.
